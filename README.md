# 企画セレクタ

Claude で量産した企画案を、1件ずつ ◯△×・保留 で捌いていくためのツール。

## 使い方

`index.html` をブラウザで開くだけ。インストールもネット接続も不要。

1. **プロンプト作成** — 条件を入れるとプロンプトができる。コピーして Claude に貼る
2. **読み込み** — Claude が返してきた表をそのまま貼り付ける
3. **評価** — 1件ずつ ◯ / △ / × / 保留。メモも書ける
4. **結果** — 集計を見て、CSV でコピーまたはダウンロード

## 覚えておくとよいこと

- **キーボード**（PC）：`1`=◯ `2`=△ `3`=× `4`=保留、`←` `→` で移動、`Enter` でメモ欄へ、`Esc` で抜ける
- **同じボタンをもう一度押すと評価を取り消せる**
- 評価すると自動で次へ進む。**末尾まで行くと、飛ばした未評価の案に戻る**。全件終わると結果ページへ移動する
- 「未評価へ飛ぶ」で、飛ばした案だけを手動で拾い直すこともできる
- 結果一覧の行をタップすると、その案の評価画面に戻る
- **スマホでは左右スワイプで評価できる**。左へ払うと ◯、右へ払うと ×（画面のボタンの並びと同じ向き）。△と保留はボタンで押す
  - 縦スクロールとぶつからないよう、横方向にはっきり動かしたときだけ反応する
  - 途中で指を離す（振り幅が小さい）と、評価されずカードが戻る

## 読み込める形式

Claude / ChatGPT / Gemini どれを使っても出力はブレるので、次のどれでも読み取れるようにしてある。

- CSV（`id,title,overview`）
- タブ区切り
- Markdown の表（`| id | title | overview |`）
- 番号付きリスト（`1. タイトル — 概要`、`1. **タイトル**：概要`）
- 「はい、承知しました」などの前置きや、末尾のまとめ文が付いていても無視する
- セル内の `**太字**` 記号は自動で外す
- ` ``` ` で囲まれたまま
- ヘッダー行なし、2列だけ、といった崩れた形

## データの保存場所

評価内容は**そのブラウザの中だけ**に保存される（localStorage）。サーバーには何も送られない。

つまり：

- 同じブラウザで開き直せば続きから再開できる
- **別の端末とは共有されない**
- ブラウザのデータを消すと評価も消える

大事な結果は「4. 結果」から CSV に書き出して保管すること。

## 制限

- 1回に扱えるのは1セット。新しい企画案を読み込むと前の評価は消える（確認ダイアログが出る）
- 150案・概要140字で保存容量は約60KB。localStorage の上限は約5MB なので、数千案までは問題ない
- スマホや埋め込み表示ではダウンロードが効かないことがある。その場合は「CSV をコピー」を使う
